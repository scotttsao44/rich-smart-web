# 工作規則

1. **動手前**：先讀 `docs/01-需求.md`、`02-架構.md`、`03-進度.md`，再寫出計畫（要改什麼、影響範圍、如何驗證、如何回滾）。
2. **存檔點**：每次變更前先 `git commit`（存檔點）；變更穩定後再提交一次。提交者 `富智慧部署 <deploy@rich-smart.com.cn>`。
3. **大改動開分支**：`git switch -c feat/<名稱>`，驗證後再合併回 `main`。
4. **完成後**：在 `03-進度.md` 追加日期與內容，並提交。
5. **絕不提交機密**：`.env*`、`*.pem`、`*.key`、`apiclient_*`、passwd、`certs/`、資料目錄、`node_modules`、`.next*`、日誌、備份壓縮檔。提交前執行 `git status` 並 grep `PRIVATE KEY` 等。
6. **回滾**：程式碼用 `git`（checkout / revert）；執行中的服務用 docker 映像標籤（部署前先 `docker tag caomi-cn-web:latest caomi-cn-web:rollback-<說明>-<日期>`）。
7. 伺服器記憶體小、沒有 Node：在別處建置，伺服器只用 `Dockerfile.prebuilt` 打包。
8. 不要動 rich-smart.net。重啟、重建、重新部署前須先取得同意。
